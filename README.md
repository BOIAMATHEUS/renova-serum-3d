# Renova Be · Sérum GHK-Cu, 3D

Visualizador do frasco e do cartucho, com os acabamentos aplicados a partir das
máscaras dos pacotes de impressão.

- Cartucho 42 × 42 × 140 mm, frasco 100 mm: as duas peças na proporção real
- Rótulo do frasco 85 × 40 mm, faixa à esquerda, 77% da volta
- Verniz brilhante só nos textos, relevo seco e relevo para dentro sem tinta
- Botão "Luz rasante" para conferir os acabamentos
